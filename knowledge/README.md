# Local policy artifacts

Generate `policies.json` with `python scripts/prepare_policies.py` using an authorized
copy of the original manual. Portuguese source text remains restricted and absent
from Git. English metadata provides document version, sections, pages, and SHA-256.

`policy_notes.md` contains the detailed English local review, including source
values that should not be republished without permission. It is also ignored.
The public `docs/policy_review.md` describes issues without copying internal
contacts or full commercial terms.

See `docs/policy_catalog.md` for the contract, complete topic map, and retrieval
semantics. Public synthetic fixtures do not replace originals in local preparation.
