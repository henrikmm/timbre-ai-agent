# Local policy artifacts

The original `policies.json` is generated by `scripts/prepare_policies.py` from an
authorized copy of the assessment manual. Portuguese source text stays restricted
and outside Git. Metadata records document version, sections, pages and SHA-256.

The public demonstration instead loads `tests/fixtures/demo/policies.synthetic.json`
into `local/demo/policies.json`. These hand-authored fictional terms use the same
catalog format and do not replace or reproduce the original manual.

See the [policy architecture](../docs/architecture.md#policy-retrieval-and-service-decisions)
and [data preparation instructions](../README.md#using-the-original-assessment-data).
